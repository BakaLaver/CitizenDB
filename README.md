# CitizenDB
<img width="1149" height="637" alt="image" src="https://github.com/user-attachments/assets/ac5c9e53-4638-41d0-bf09-a7e6f3fc3833" />

**CitizenDB** — десктопное приложение, которое превращает входной файл с данными в аккуратный Excel-файл со всеми жителями города.

Закинули файл в окно — если всё хорошо, на выходе получаете готовую таблицу. Если файл не подходит, программа сообщит об ошибке и не создаст мусорный результат.

## ✨ Возможности

- **Drag & Drop** — достаточно перетащить файл в область окна приложения.
- **Валидация входных данных** — проверка формата, целостности и содержимого файла.
- **Экспорт в Excel** — при успешной обработке генерируется `.xlsx`-файл со структурированным списком жителей.
- **Простота** — никаких настроек и лишних шагов: закинул файл → получил результат.

## 🚀 Как использовать

1. Запустите приложение `CitizenDB.exe`.
2. Перетащите подготовленный файл в область окна.
3. Дождитесь окончания обработки.
4. Заберите готовый Excel-файл со списком жителей.

## 🛠 Технологии

- **Язык:** C#
- **Платформа:** .NET (Windows Desktop)
- **IDE:** Visual Studio (solution `CitizenDB.sln`)
- **Экспорт:** Excel (`.xlsx`)
